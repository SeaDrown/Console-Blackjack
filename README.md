## Blackjack Java Edition

This is a simple console app that lets the user play blackjack. It is coded entirely in Java.
You will require a JVM to run this application (obviously)

This was created with my prior experience creating blackjack in Python. Because of this, as well as good OOP
fundamentals, this project only took me 1 day. I am quite happy with the short development time, since I only
started coding in Java a few days ago. :D
