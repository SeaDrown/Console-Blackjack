## Blackjack Java Edition

This is a simple Java console app that lets the user play blackjack against the CPU dealer. To run this, you will require a JVM, and must compile the binary yourself.

This was created back in Sept. 2025, after I had made blackjack in Python. I used the knowledge I gained from my first year of university, such as OOP principles and debugging to recreate blackjack in Java. Since I had just started learning Java recently (beginning my second year of university), this was a great project to really learn how Java behaves differently to Python, and what it means for creating applications.
